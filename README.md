# Simple Interest Calculator

A simple Bash calculator that calculates simple interest based on the principal amount, rate of interest, and time period.

## Features

* Takes the principal amount as input
* Takes the rate of interest as input
* Takes the time period as input
* Calculates simple interest

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

## Inputs

The calculator requires three inputs:

1. Principal amount
2. Rate of interest
3. Time period

## Description

This project is a simple interest calculator developed using Bash scripting. It allows users to enter the principal amount, rate of interest, and time period and then calculates the simple interest.
